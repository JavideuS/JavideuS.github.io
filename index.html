🔬 Spooky — Multi-Robot Path Planning via QUBO

June 2025 - Present | Pre-print on arXiv

Multi-robot path planning formulated as a Quadratic Unconstrained Binary Optimization problem, with quantum and classical solvers behind one API.

  • Over 95% variable reduction through BFS-based preprocessing; time-windowed decomposition for current hardware
  • Run on real quantum hardware (IBM Quantum Platform, IQM Resonance), plus PennyLane QAOA and D-Wave annealing
  • Classical ILP and CBS baselines, with a benchmark framework to compare them
Python QUBO Qiskit PennyLane D-Wave Ocean FastAPI

🧵 clew — Fleet Coordinator for ROS2/Nav2

2026

Takes Spooky's plan to real robots: it decides when each robot may drive the next stretch of its own path, and leaves the driving to Nav2.

  • Turns the global plan into per-robot release schedules around conflict zones
  • Executes through each robot's own Nav2 stack, with stall and deadlock recovery

🤖 argOS — Natural-Language Robot Control

May 2026 - Present | RoboHack 2026 Winner

A browser interface to command robots in plain language, bringing teleoperation, semantic understanding and real-time 3D visualization into one place. No ROS expertise required to operate the robot.

  • Natural language commands via an LLM agent with MCP tool access to navigation and perception
  • Live 3D lidar pointcloud in the browser (WebGL) and a semantic object memory built from YOLO detections
  • Works over the internet via a cloud-to-robot bridge; no VPN or direct network path needed
  • Fleet interface for Spooky and clew: shared map, multi-robot view and control (on the work branch)

ROS2 Packages

transformers_bridge — ROS2 ↔ HuggingFace Bridge

Object detection for robotics

ROS2 package for object detection using HuggingFace Transformers and Ultralytics YOLO. A single LifecycleNode supports both backends and outputs standard vision_msgs/Detection2DArray.

  • Backend (HuggingFace or YOLO) swappable at runtime without restarting the node
  • Inference runs on a background thread, so the ROS executor is never blocked
  • Configurable via YAML; extensible through simple class inheritance
Python ROS2 HuggingFace Ultralytics YOLO PyTorch

aries_ros and plansys2_aries_plan_solver — Aries Planner for ROS2

PDDL/HDDL task planning

A ROS2 wrapper for the Rust-based Aries planner, compiled via Cargo as part of the Colcon build, and a PlanSys2 plugin that uses it as a drop-in replacement for POPF/TFD.

  • Supports durative actions and HDDL domains
  • Configured via YAML through pluginlib; no changes to PlanSys2 source required
C++ ROS2 PlanSys2 PDDL Rust
