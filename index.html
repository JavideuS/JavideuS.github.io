June 2025 - February 2026 | Pre-print on arXiv

🤖 argOS — Modern Cloud Layer for Robot Teleoperation

May 2026 | RoboHack 2026 Winner

A platform that brings together teleoperation, natural language navigation, semantic understanding, and real-time 3D visualization into a single browser interface. No ROS expertise required to operate the robot.

  • Natural language commands via LLM agent (Claude/AWS Bedrock) with MCP tool access to navigation and perception
  • Live 3D lidar pointcloud in the browser (WebGL, height-mapped) for real-time situational awareness
  • Semantic object memory — YOLO11 detects and maps the environment, with confidence decay and S3 persistence
  • Works over the internet via a cloud-to-robot MCP bridge; no VPN or direct network path needed
  • Currently wraps DimOS navigation backend; designed to support ROS2/Nav2 and others
Python ROS2 AWS Bedrock FastAPI WebGL YOLO11

ML

transformers_bridge — ROS2 ↔ HuggingFace Bridge

Object detection for robotics

ROS2 package for object detection using HuggingFace Transformers and Ultralytics YOLO. A single LifecycleNode supports both backends and outputs standard vision_msgs/Detection2DArray, designed to be subclassed by downstream perception stacks.

  • Backend (HuggingFace or YOLO) swappable at runtime without restarting the node
  • Inference runs on a background thread — ROS executor is never blocked
  • Configurable via YAML; extensible through simple class inheritance
